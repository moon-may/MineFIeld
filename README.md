## Игра Сапёр
Собственная реализация классической игры "Сапёр" (консольная версия) с покрытием ядра тестами. 

### Правила
На поле размером *m x n* случайным образом расставлено *k* мин. Игрок может открыть клетку или обозначить её флажком - отметить предполагаемую мину.  

Число в открытой клетке показывает, сколько мин находится в соседних клетках (по горизонтали, вертикали или диагонали).  

При открытии пустой клетки (число 0) автоматически открываются все соседние пустые клетки до границ с числами.  

**Игрок проиграл**, если открыта клетка с миной.  
**Игрок выиграл**, если открыты все безопасные клетки.  

### Структура проекта
  - В `mine_field.py` хранится ядро игры: генерация поля, логика открытия ячеек, расстановки флагов, проверка победы 
  - `console_game.py` — консольная версия: отрисовка поля, обработка ввода, игровой цикл
  - `tests/test_mine_field.py` — тесты на ядро игры

### Запуск
Программа использует только стандартные библиотеки Python, дополнительная установка пакетов не требуется.
Для запуска игры: 
```bash
python console_game.py
```

#### Запуск тестов
```bash
pip install pytest
pytest tests/ -v
```

### Технологии
  - Python 3.14
  - pytest
